# RunLog — 설치형(PWA) 버전

서버 없이 휴대폰 안에서만 동작하는 개인 러닝 기록·분석 앱입니다.
기록(GPX 등)은 휴대폰 브라우저 저장소(IndexedDB)에만 저장되고, 어디로도 전송되지 않아요.

## 파일
- `index.html` — 앱 전체(지도 라이브러리 포함, 단일 파일)
- `sw.js` — 오프라인 실행, 다른 앱에서 GPX '공유하기'로 받기
- `manifest.webmanifest`, `icon-*.png` — 홈 화면 설치용

## 휴대폰에 설치하기 (GitHub Pages, 무료)
1. github.com 가입 → 새 저장소 만들기(예: `runlog`)
2. 저장소에서 **Add file → Upload files** → 이 폴더의 파일 전부 업로드 → Commit
3. 저장소 **Settings → Pages** → Branch: `main`, 폴더: `/ (root)` → Save
4. 1~2분 뒤 `https://<아이디>.github.io/runlog/` 를 갤럭시의 **크롬**으로 열기
5. 크롬 메뉴(⋮) → **홈 화면에 추가 / 앱 설치**

> 저장소에는 앱 코드만 올라가요. 러닝 기록은 휴대폰에만 남아요.
> 설치 후에는 삼성헬스·파일 앱에서 GPX를 **공유 → RunLog**로 바로 보낼 수 있어요.

## 가져올 수 있는 파일
- GPX (심박·케이던스 확장 포함), TCX, `.gpx.gz`
- 삼성헬스 GPX에 케이던스가 없으면: 삼성헬스 → 설정 → 개인 데이터 다운로드 → 해당 운동의
  `…exercise.live_data.json` 파일을 가져오면 같은 시간대 기록에 케이던스를 합쳐요.
- RunLog 백업 파일(.json) — 다른 기기로 옮기거나 복원할 때

## 백업
설정 → 백업 파일 내보내기. 브라우저 데이터를 지우거나 앱을 삭제하면 기록도 사라지니 가끔 백업해 두세요.
